Документооборот / Импорт

Импорт входящего документа через MagicPad: загрузка, распознавание полей, выбор процесса и создание экземпляров (экраны U1–U9).

Экраны U1–U5 выгружены из Figma (экспорт 19.10.2026) и кликабельны: зоны клика расставлены по кнопкам на макетах, шаги обработки файла переключаются по таймеру. Путь: команда в MagicPad, прикрепление и отправка файла, ответ агента с выбором процесса, общие данные, распознанные поля с добавлением поля по фрагменту документа, создание процесса (U5). Экраны U6–U9 и кадр U4.1 выгружены вторым экспортом (19.10.2026): процессы «Стройка контрагенты», «Стройматериалы», «Приёмка товара / Мат поток» и мат поток с отсутствующими контрагентами и товаром. Зоны клика стоят на явных кнопках (меню строки, «Редактировать», «Сохранить», «Создать», CTA в MagicPad), остальные шаги идут по кнопке «Далее». В U9 повторно используются экраны из U2, U6 и U7, картинки у них общие. Два оверлея U7 в экспорт не вошли.
